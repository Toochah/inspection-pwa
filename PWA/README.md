## 📋 Типы обходов

### 1. 🔵 Обход дежурного (ПОЛНОСТЬЮ НАПОЛНЕН)

**Описание:** Ежедневный обход по 23 точкам с QR-кодами

| Параметр | Значение |
|----------|----------|
| **Точек** | 23 |
| **QR-коды** | ✅ Есть |
| **GPS** | ✅ Есть (5м) |
| **Чек-листов** | 10 типов (71 пункт) |
| **Время прохождения** | 60-90 минут |

**Оборудование:**
- Вентустановки (VENT-01, VENT-02) - 4 пункта
- КНС (KNS-01, KNS-02, KNS-03) - 2 пункта
- ИТП (ITP-01, ITP-02, ITP-03) - 5 пунктов
- ГРЩ (GRSH-01, GRSH-02, GRSH-03) - 5 пунктов
- ДГУ (DGU-01, DGU-02, DGU-03) - 2 пункта
- Котельная (BOILER-01) - 5 пунктов
- Насосная (PUMP-01) - 4 пункта
- Эваквыходы (EXIT-01..04) - 1 пункт
- Освещение (LIGHT-OUT, LIGHT-EMG) - 3+2 пункта
- Территория (TERR-WINTER) - 3 пункта

**Каждая точка содержит:**
- 📍 Расположение
- 📝 Подробное описание
- 🔧 Тип оборудования
- 🏭 Производитель
- 📅 Год установки
- ⚡ Мощность (для ДГУ)
- ✅ Чек-лист с пунктами
- 📊 Нормальные значения

**Документация:** [`GUARD_ROUTE.md`](GUARD_ROUTE.md) - полная документация по всем 23 точкам

## 🎯 Как использовать

### 1. Авторизация

1. Откройте http://localhost:8080
2. Выберите сотрудника из списка (19 человек)
3. Должность подставится автоматически
4. Выберите роль (Дежурный / Инженер / Специалист)
5. Нажмите "Войти"

### 2. Выбор типа обхода

После авторизации откроется экран выбора типа обхода:
- **Обход дежурного** - 23 точки с QR (полностью наполнен)
- **Обход DoorHan** - шлагбаумы и ворота (шаблон)
- **Вентиляция и кондиционирование** - системы ВиК (шаблон)
- **КИПиА** - приборы и автоматика (шаблон)

### 3. Начало обхода

1. На дашборде нажмите "Начать обход"
2. Перейдите в раздел "Маршрут"
3. Выберите точку из списка
4. Отсканируйте QR-код или введите код вручную
5. Пройдите чек-лист
6. Отметьте точку как пройденную

### 4. Детали точки

При открытии точки отображается:
- 📍 Расположение
- 📝 Описание
- 🔧 Тип оборудования
- 🏭 Производитель
- 📅 Год установки
- ⚡ Мощность
- ✅ Чек-лист с описанием
- 📊 Нормальные значения

### 5. Завершение обхода

1. Пройдите все точки
2. Прогресс покажет 100%
3. Отчёт сохранится автоматически

## 🐛 Проблемы?

### Не видно список сотрудников?
1. Очистите кэш браузера: `Ctrl+Shift+Delete`
2. Перезагрузите страницу: `Ctrl+R`
3. Проверьте консоль: `F12` → Console

### Не работает камера?
- Требуется HTTPS или localhost
- Разрешите доступ к камере в браузере

### Сбросить сессию?
На экране авторизации нажмите кнопку **"Сбросить сессию"**
