# 📖 Инструкции по обходу для разных специалистов

## 👥 Роли в системе

| Роль | Описание | Доступные обходы |
|------|----------|------------------|
| **Дежурный персонал** | Обходчик, дворник | Обход дежурного (23 точки) |
| **Инженер** | Главный инженер, инженер по эксплуатации | Все обходы + просмотр отчётов |
| **Специалист** | Техник по конкретному оборудованию | Профильные обходы |

## 🔵 Инструкция дежурного персонала

### Кто может выбрать
- Асеев Олег Николаевич (Дворник)
- Биктуганова Кристина Андреевна (Уборщица)
- Кузнецов Олег Александрович (Дворник)

### Доступный обход
**Обход дежурного** - 23 точки с QR-кодами

### Пошаговая инструкция

#### 1. Начало смены
1. Откройте приложение
2. Выберите свою фамилию из списка
3. Выберите роль "Дежурный персонал"
4. Нажмите "Войти"
5. Выберите тип обхода "Обход дежурного"

#### 2. Прохождение маршрута
1. Нажмите "Начать обход"
2. Перейдите в раздел "Маршрут"
3. Следуйте по точкам от 1 до 23
4. На каждой точке:
   - Отсканируйте QR-код (раздел "Сканер")
   - Или введите код вручную (например: VENT-01)
   - Отметьте пункты чек-листа
   - При дефекте - добавьте фото и описание

#### 3. Особые указания
- **Эваквыходы (5, 8, 18, 20):** Проверить свободный доступ
- **Территория (23):** Зимой проверить уборку снега
- **Освещение (21, 22):** Проверить все линии

#### 4. Завершение обхода
1. Пройдите все 23 точки
2. Отчёт сохранится автоматически
3. Сообщите инженеру о дефектах

**Доступна всем ролям!**

### Когда нажимать
- Пожар или задымление
- Прорыв трубы
- Отключение электричества
- Угроза безопасности

### Что происходит
1. Уведомление отправляется всем инженерам
2. Создаётся запись в журнале инцидентов
3. Требуется фото ситуации

## 📊 Отчётность

### Дежурный персонал
- Ежедневный обход (утро/вечер)
- Отчёт сохраняется автоматически
- Дефекты отправляются инженеру

### Инженер
- Еженедельный анализ отчётов
- Сводка по дефектам
- План устранения неисправностей

### Специалист
- Периодический обход (по графику)
- Расширенные отчёты с параметрами
- Рекомендации по ремонту

## 📱 Советы по использованию

### Быстрый старт
1. Сохраните сессию (не выходите из приложения)
2. Используйте QR-коды для быстрого доступа
3. Фотографируйте все дефекты

### Экономия времени
1. Пройдите маршрут по порядку
2. Используйте фильтр "Не пройденные"
3. Вводите код вручную если QR не читается

### Безопасность
1. Не пропускайте точки с эваквыходами
2. Проверяйте освещение в тёмное время
3. Сообщайте о любых неисправностях
