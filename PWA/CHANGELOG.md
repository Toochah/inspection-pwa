# 📋 Changelog - Склад.Инспект PWA

## [2.1.0] - 2026-03-23

### ✨ Новое
- **Таймер обхода** - отсчёт времени с начала обхода в реальном времени
- **Карточка следующей точки** - показывает следующую непройденную точку с расстоянием
- **Горизонтальный прогресс-бар** - визуализация прогресса обхода
- **Улучшенная статистика** - 4 карточки с цветовыми индикаторами
- **Версионирование** - информация о версии выводится в консоль (F12)
- **Авто-определение роли** - роль выбирается автоматически при выборе сотрудника

### 🎨 Улучшения
- **Дизайн карточек точек** - цветные полоски статуса слева
- **Пульсация текущей точки** - анимация для активной точки
- **Увеличенные чекбоксы** - удобнее нажимать на мобильных
- **Нормальные значения** - отображение рекомендуемых параметров в чек-листах
- **Улучшенная загрузка фото** - большая область клика, предпросмотр 120x120px

### 🐛 Исправления
- **Пустое окно после входа** - исправлено переключение видов
- **Ошибки textContent** - добавлены проверки на существование элементов
- **404 на иконки** - используется SVG вместо PNG
- **Deprecated warning** - добавлен mobile-web-app-capable meta tag

### 🔧 Технические изменения
- **Модульная структура** - разделение логики по функциям
- **Очистка кэша** - кнопка в настройках для сброса
- **Service Worker** - обновлён для лучшего кэширования

## 📝 Формат версий

Формат: `[МАЖОРНАЯ.МИНОРНАЯ.ПАТЧ] - ГГГГ-ММ-ДД`

- **МАЖОРНАЯ** - несовместимые изменения API
- **МИНОРНАЯ** - новая функциональность (обратно совместимая)
- **ПАТЧ** - исправления багов (обратно совместимые)
