## 🎨 Дизайн-система

### Цветовая схема

| Элемент | Цвет | Значение |
|---------|------|----------|
| **Пройдено** | `#2e7d32` (зелёный) | Точка пройдена без дефектов |
| **Дефект** | `#d32f2f` (красный) | Обнаружен дефект |
| **В процессе** | `#1976d2` (синий) | Текущая точка |
| **Ожидание** | `#757575` (серый) | Ещё не пройдена |
| **Внимание** | `#ed6c02` (оранжевый) | Требует внимания |

### Иконки

| Категория | Иконка |
|-----------|--------|
| ОВиК | `ac_unit` |
| Водоотведение | `water_drop` |
| Теплоснабжение | `local_fire_department` |
| Электроснабжение | `flash_on` |
| Резервное питание | `power` |
| ПБ | `fire_extinguisher` |
| Водоснабжение | `plumbing` |
| Освещение | `lightbulb` |
| Территория | `landscape` |

## 📊 Статистика обхода

### В реальном времени

- Пройдено точек: X/23
- Время в пути: ЧЧ:ММ:СС
- Обнаружено дефектов: X
- Среднее время на точку: ММ:СС

### По завершении

- Общее время обхода
- Процент выполнения: 100%
- Количество дефектов
- Экспорт в отчёт
