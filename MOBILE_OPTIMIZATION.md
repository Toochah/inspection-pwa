# 📱 Мобильная оптимизация PWA "Склад.Инспект"

**Версия:** 2.1.0  
**Дата:** Март 2026

---

## 🎯 Цель оптимизации

Приложение оптимизировано для использования на мобильных устройствах (смартфоны, планшеты) с сенсорным управлением.

---

## ✨ Мобильные функции

### 1. **Адаптивный дизайн**

```css
/* Оптимизация для мобильных экранов */
- viewport-fit=cover для iPhone с челкой
- safe-area-inset для отступов
- touch-action: manipulation для быстрого отклика
- min-height: 48px для всех кнопок (рекомендации Material Design)
```

### 2. **Сенсорное управление**

| Жест | Действие |
|------|----------|
| **Тап** | Выбор элемента |
| **Долгий тап** | Блокируется (нет контекстного меню) |
| **Свайп вправо** | Возврат к дашборду |
| **Скролл** | Плавная прокрутка с inertia |

### 3. **Haptic Feedback (Вибрация)**

```javascript
// Вибрация при действиях
vibrate(5)    // Переключение вкладок
vibrate(10)   // Нажатие кнопки
vibrate([10, 30, 10])  // Успех
vibrate([50, 30, 50, 30, 50])  // Ошибка
```

**Поддержка:** Android ✅, iOS ❌ (ограниченно)

### 4. **Оптимизация камеры**

```javascript
const constraints = {
    video: {
        facingMode: 'environment', // Задняя камера
        width: { ideal: 1280 },
        height: { ideal: 720 }
    }
};
```

**Преимущества:**
- Автоматически выбирает заднюю камеру
- Оптимальное разрешение для QR сканирования
- Быстрая загрузка потока

### 5. **Сжатие изображений**

```javascript
// Сжатие фото перед отправкой
compressImage(file, 1024, 1024, 0.8)
// Результат: JPEG 80% качества, макс. 1024px
```

**Экономия:**
- Оригинальное фото: 3-5 MB
- Сжатое фото: 200-500 KB
- Экономия трафика: ~90%

### 6. **Lazy Load для списков**

```javascript
// Загрузка точек по мере скролла
IntersectionObserver → загрузка следующих 10 точек
```

**Преимущества:**
- Быстрая начальная отрисовка
- Меньше потребление памяти
- Плавный скролл

## 🚀 Производительность

### Оптимизации

1. **CSS**
   - Минимизирован (1 файл)
   - Без тяжелых анимаций
   - GPU-ускорение для transform

2. **JavaScript**
   - Ленивая загрузка модулей
   - Debounce для частых событий
   - RequestAnimationFrame для анимаций

3. **Изображения**
   - SVG иконки вместо PNG
   - Lazy loading
   - Сжатие JPEG 80%

4. **Кэш**
   - Service Worker кэширует статику
   - LocalStorage для данных
   - IndexedDB для фото

## 🔧 Настройки для мобильных

### Meta теги

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="mobile-web-app-capable" content="yes">
<meta name="format-detection" content="telephone=no">
<meta name="msapplication-tap-highlight" content="no">
```

### CSS переменные

```css
:root {
    --safe-area-top: env(safe-area-inset-top);
    --safe-area-bottom: env(safe-area-inset-bottom);
    --touch-target-min: 48px;
    --bottom-nav-height: 64px;
}
```

## 💡 Советы по использованию

### Для пользователей

1. **Установите как приложение**
   - Android: Меню → "Установить приложение"
   - iOS: "Поделиться" → "На экран «Домой»"

2. **Разрешения**
   - Камера: требуется для QR сканера
   - Геолокация: для GPS валидации
   - Уведомления: для аварийных уведомлений

3. **Офлайн режим**
   - Работает без интернета
   - Данные синхронизируются при подключении

### Для разработчиков

1. **Тестирование**
   ```bash
   # Chrome DevTools → Device Mode
   # Выберите устройство из списка
   # Проверьте touch-события
   ```

2. **Отладка на устройстве**
   ```
   Chrome: chrome://inspect
   Safari: Develop → [устройство]
   ```

3. **Lighthouse аудит**
   ```
   DevTools → Lighthouse → Mobile
   ```
